PACE 校園運動
運動模板教學講義

用手機，把校園走成一張地圖。

Android 與 iPhone 的使用形式

本模板是可加入主畫面的響應式網頁（PWA），不是 APK 或 App Store 原生 App。同一份 HTTPS 網址可在 Android Chrome 與 iPhone Safari 開啟，不必另外開發兩套介面。

AndroidiPhone
用 Chrome 開啟 HTTPS 網址 → 允許位置與精確定位 → 瀏覽器選單中使用「加到主畫面」或「安裝」（名稱依版本而異）。用 Safari 開啟 HTTPS 網址 → 允許位置與精確定位 → 分享選單 →「加入主畫面」（名稱依版本而異）。

安裝選項依瀏覽器及系統版本而異，即使沒有安裝按鈕也可以直接用網頁。首次開啟需連網；介面可快取，但校園底圖仍需網路。

學生操作流程

  1. 按「開始運動」，在設定視窗輸入暱稱、身高、體重、年齡，選擇活動方式。
  2. 閱讀並勾選資料記錄同意；按「開始 GPS 運動」。若只是測試，按「先體驗示範運動」。
  3. 在戶外等待第一個精度合格的定位點；成功後才開始計時。
  4. 保持頁面前景及螢幕亮著。切換 App 或鎖屏可能觸發自動暫停；返回後按繼續。休息時手動暫停。
  5. 結束並儲存。從歷程匯出 CSV 摘要或 JSON 軌跡，可刪除單筆或全部紀錄。

網站部署與使用

本網站使用純靜態網頁，不需要登入或資料庫。運動紀錄存在目前瀏覽器，可自行匯出備份。

  1. 部署至支援 HTTPS 的靜態網站主機，例如 GitHub Pages。
  2. 確保網站未禁止位置權限；手機請開啟 HTTPS 網址，電腦本機可使用 localhost。
  3. 先用 Android 與 iPhone 測試定位、走 100–200 公尺、暫停繼續、切換背景與匯出。
  4. 運動前自行確認路線安全與天候，遵守現場標示。

課前實測清單

  • 能直接進入運動頁面，無需登入。
  • 拒絕定位時顯示說明，不會產生假 GPS 軌跡。
  • 示範紀錄明確標示，不能當成真實出席證明。
  • 同一路線兩次量測的差異可接受，確認不會穿越禁止通行區域。
  • 匯出的 CSV 能在一般試算表開啟。

回顧運動數據

在「運動紀錄」匯出軌跡 JSON，再點選「運動分析」載入。可以展開紀錄與定位品質、熱量比較、斷段原因、距離與速度驗算；CSV 摘要則用於查看多筆紀錄。

目前範圍與擴充方向

已包含：手機版地圖、定位軌跡、時間／距離／ACSM 熱量估算、資料缺口提示、原始點與篩選原因保存、示範、個人歷程、匯出與匯入檢視。紀錄儲存在目前裝置的瀏覽器中，沒有自動上傳功能。

若日後要長時間鎖屏持續記錄，需另行開發具原生背景定位權限的 Android／iOS App，並實機驗證耗電、權限與商店政策；只把網頁包裝成 App 不會自動解決背景定位。
